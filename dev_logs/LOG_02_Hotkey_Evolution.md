# 開發日誌 02：快捷鍵策略演進

**日期：** 2026-05-01
**狀態：** 已完成

## 任務摘要
- 實現 `VolumeKeyStateMachine` 狀態機邏輯。
- 從「三擊」優化為「並按」，最終確立為「序列型」觸發。

## 變更內容
- **v1.0**: 長按音量上 + 連按三下音量下（測試發現實體按鍵過於吃力）。
- **v1.1**: 音量上 + 下同時按（測試發現容易誤觸系統音量調整）。
- **v1.2 (Final)**: 序列偵測 `UP -> DOWN -> DOWN`。
  - 加入 1800ms 時間窗。
  - 加入 1000ms 冷卻時間。
  - 支援 `DOWN -> UP -> UP` 作為錄影功能預留。

## 測試結果
- 在 Samsung A16 上成功實現不看螢幕觸發錄音。
- 成功過濾長按產生的重複事件 (Repeat Events)。
